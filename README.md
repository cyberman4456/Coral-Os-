
# Coral OS 🪸

A mobile-first Linux operating system built on Alpine Linux.

## Vision

Coral OS aims to provide an independent, lightweight,
secure and customizable mobile operating system.

## Architecture

- Linux kernel
- Alpine Linux foundation
- ARM64 mobile target
- Custom Coral user interface
- Native Coral Package system (CPK)
- Android application compatibility layer
- Independent application marketplace

## Development principles

1. Understand every major component.
2. Build incrementally.
3. Prefer open standards.
4. Minimize unnecessary dependencies.
5. Prioritize security and user privacy.
6. Document architectural decisions.
